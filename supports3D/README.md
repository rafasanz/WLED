# 3D-printable supports

This folder contains STL models used by the ESP32-S3-N16R8 HUB75 hardware setup
documented in `docs/esp32-s3-n16r8-hub75.md`.

## Models

- `ESP_32_S3_Dual_USB-C_Dev_Kit_Case_v2.stl`: case for the dual USB-C
  ESP32-S3 development board.
- `hub75+esp32-44pin.stl`: support for mounting the HUB75 connector together
  with the 44-pin ESP32-S3 board.
- `LED_panel_mount_v1_arm.stl`: mounting arm for the LED panel.

These mechanical files are specific to this fork and are not part of upstream
WLED.
